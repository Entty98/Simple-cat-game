## 👾-A very simple two-dimensional game written in C# and Visual Studio Code.

## 📖-In this game, the player is a cat on a map who must prevent onions from being lost by catching them. He receives a positive point for each onion he catches and a negative point for each onion he loses.

## 📌-Note: This project is purely a practice and is not intended to infringe on copyright or the overall project aspect.
