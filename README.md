# Simple Cat Game

A very simple two-dimensional game written in C# and developed using Visual Studio Code.

## Overview

In this game the player controls a cat on a small map. The goal is to catch falling onions before they are lost. The player receives a positive point for each onion caught and a negative point for each onion lost.

## Gameplay

- Player: a cat that the user moves around the map.
- Objects: onions appear and the cat must catch them.
- Scoring: +1 for each onion caught, -1 for each onion lost.

## Project structure (high level)

- Source code: C# files containing the game logic (e.g., Program.cs, Game.cs, Player.cs).
- Assets/: images and sounds used by the game (sprites, background, etc.).
- Information.md: additional documentation.

## How to run (basic)

1. Open the project folder in Visual Studio Code or another C#-capable IDE.
2. Make sure you have the .NET SDK or a compatible runtime installed if the project targets .NET. (If the project uses a different runtime or engine, follow the specific instructions in Information.md.)
3. Build and run the project from the IDE or using the appropriate command (for .NET projects: `dotnet run` in the project directory).

Note: This project was created as a practice exercise and may use simple project settings suitable for learning. If you run into build/runtime issues, check the project files or open an issue describing the problem.
